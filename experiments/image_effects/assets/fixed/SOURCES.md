# Fixed images for Exp 3 (peace / war / neutral)

Put 3 images per folder (`peace/`, `war/`, `neutral/`; png/jpg/webp). Each file becomes one
condition `exp3_<category>_<file stem>`: the 90 open-ended questions, all with that image.

Rules (so the experiment stays clean and shareable):
- Use images with a free license (Wikimedia Commons CC0 / CC BY / public domain, Unsplash
  license). Record every file below: file name, source URL, author, license.
- "war": not graphic (no gore or corpses), e.g. tanks, ruined buildings, soldiers, smoke.
- "peace": e.g. people embracing, a calm park, a peace demonstration, doves.
- "neutral": everyday, emotionally flat scenes, e.g. an office desk, a parking lot, a kitchen.
- Similar resolution (~1024 px on the long side) and no text/logos in the image, so that
  size and readable text are not confounds.
